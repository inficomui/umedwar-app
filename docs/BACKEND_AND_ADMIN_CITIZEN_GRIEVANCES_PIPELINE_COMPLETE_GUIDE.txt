1. EXECUTIVE SUMMARY & ROOT CAUSE ANALYSIS (तक्रारी का दिसत नव्हत्या?)
================================================================================

PROBLEM STATEMENT:
When citizens submitted complaints through the "नागरिक सेवा व तक्रार" section in
the mobile app, the complaints did not appear in the Web Admin Panel, and the
pipeline (status progression, 24-hr SLA, officer assignment, actions) was not
working.

TECHNICAL ROOT CAUSE & FINDINGS:
1. Data Silo Discrepancy:
   - Channel A (`issues` table / `POST /api/v1/issues`):
     Used by the old "समस्या नोंदवा (Report Issue)" screen. The existing Admin Panel
     was hardcoded to only query `GET /api/v1/issues`.
   - Channel B (`citizen_submissions` table / `POST /api/v1/citizen-services/submissions`):
     Used by the 26-department "नागरिक सेवा व तक्रार" section. It stores data into
     the `citizen_submissions` table.
   - Because the Admin Panel dashboard was ONLY querying Channel A, submissions in
     Channel B remained completely invisible to the admin!

2. Missing Backend Pipeline Routes:
   - When an admin attempts to assign an officer or log an action:
     `POST /api/v1/admin/citizen-services/submissions/:id/action` returned HTTP 404 (Route not found).
     `PUT /api/v1/admin/citizen-services/submissions/:id` returned HTTP 404.
   - The backend lacked the pipeline endpoints for:
     * Officer assignment (`/assign`)
     * Timeline action logging (`/action`)
     * 24-hour SLA first progress update (`/sla-update`)
     * Grievance resolution with certificate/summary (`/resolve`)
     * Grievance rejection with official reason (`/reject`)

3. Missing Web Admin Panel Pipeline UI:
   - The Web Admin Panel lacked a dedicated 26-department Kanban / pipeline board
     with 24-hour SLA countdown clocks, officer assignment dropdowns, and timeline
     auditing.

THE RESOLUTION PROVIDED IN THIS GUIDE:
- Mobile App Dual-Sync: Automatically syncs complaints to BOTH `citizen_submissions`
  and `issues` tables, guaranteeing immediate visibility in the legacy complaints list.
- Unified Backend Pipeline API: Fully implemented controller and routes for all
  pipeline lifecycle stages.
- Dedicated Web Admin Panel Pipeline Component: A production-ready React component
  with live 24h SLA timers, officer assignment, and interactive citizen chat.

2. COMPLETE 6-STAGE CITIZEN GRIEVANCE REDRESSAL LIFECYCLE (PIPELINE ARCHITECTURE)
================================================================================

```
[ 1. नवीन प्राप्त (Received) ] 
       │  (२४-तास SLA टायमर सुरू होतो)
       ▼
[ 2. छाननी व पडताळणी (Under Review) ]
       │  (प्राधान्यता: Normal / High / Urgent, संवेदनशीलता तपासणी)
       ▼
[ 3. विभाग व अधिकारी नेमणूक (Assigned to Officer) ]
       │  (२६ शासकीय विभागांपैकी संबंधित विभाग व नोडल अधिकारी नेमणे)
       ▼
[ 4. २४-तास प्रथम प्रगती अद्यतन (First 24-Hr SLA Update) ]
       │  (नागरिकाला पहिला अधिकृत प्रगती अहवाल देणे -> SLA Met ✅)
       ▼
[ 5. प्रत्यक्ष काम प्रगतीपथावर (In Progress / Action Initiated) ]
       │  (जागेची पाहणी, ठेकेदार समन्वय, टाईमलाईन कृती नोंदणी)
       ▼
[ 6. निकाली / पूर्ण (Resolved / Redressed) ] ── किंवा ── [ फेटाळले (Rejected) ]
   (निराकरण अहवाल, प्रमाणपत्र, SMS/WhatsApp/Push)           (अधिकृत कारणासह बंद)
```

STAGE DETAILS:
- Stage 1: `received` (प्राप्त)
  * Generated Reference Number (e.g. `CSK-2026-000003`).
  * SLA Timer Initiated: `first_update_due_at = NOW() + INTERVAL 24 HOUR`.
  * `sla_status` = 'pending'.

- Stage 2: `under_review` (छाननी)
  * Admin verifies citizen name, village, mobile, and complaint substance.
  * Tags priority (`normal`, `high`, `urgent`) and `is_sensitive` (true/false).

- Stage 3: `assigned` (वर्ग केले)
  * Admin assigns the complaint to one of the 26 Government Departments.
  * Assigns an official Nodal Officer (Name, Designation, Contact Number).
  * Auto-logs timeline action: "तक्रार संबंधित अधिकारी [नाव, पद] यांच्याकडे वर्ग केली गेली."

- Stage 4: `sla_updated` (२४-तास प्रथम प्रगती अद्यतन)
  * Admin/Officer sends initial progress update:
    e.g. "आपल्या अर्जाची संबंधित अधिकाऱ्यांशी चर्चा झाली असून प्रत्यक्ष पाहणी उद्या केली जाईल."
  * `first_update_sent_at = NOW()`, `sla_status = 'met'`.
  * If 24 hours lapse without an update, `sla_status = 'breached'` (Red warning badge).

- Stage 5: `in_progress` (काम चालू)
  * Ongoing timeline actions logged (site visits, material sanction, work commencement).
  * Citizen can track every step in real-time in `src/app/submission-tracking.tsx`.

- Stage 6: `resolved` (निकाली / पूर्ण)
  * Admin/Officer logs resolution summary and uploads proof/certificate.
  * Status set to `resolved`, `resolved_at = NOW()`.
  * Automated Push Notification & WhatsApp message sent to citizen.

- Alternate Stage: `rejected` / `closed` (फेटाळले / बंद)
  * If the grievance is sub-judice, duplicate, or out of jurisdiction, an official
    justification is recorded and communicated to the citizen.

-- 1. Departments Table (26 Government Offices in Kopargaon)
CREATE TABLE IF NOT EXISTS `citizen_departments` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255) NOT NULL,
  `code` VARCHAR(100) NOT NULL UNIQUE,
  `description` TEXT NULL,
  `icon` VARCHAR(100) DEFAULT 'Building2',
  `department_type` VARCHAR(100) DEFAULT 'general_governance',
  `responsible_office_name` VARCHAR(255) NULL,
  `office_address` VARCHAR(255) NULL,
  `contact_number` VARCHAR(50) NULL,
  `official_contact` VARCHAR(50) NULL,
  `official_portal_url` VARCHAR(255) NULL,
  `emergency_contact` VARCHAR(50) NULL,
  `display_order` INT NOT NULL DEFAULT 1,
  `is_active` TINYINT(1) NOT NULL DEFAULT 1,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_cd_code` (`code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 2. Nodal Officers Directory Table
CREATE TABLE IF NOT EXISTS `citizen_officers` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `department_id` INT UNSIGNED NOT NULL,
  `name` VARCHAR(255) NOT NULL,
  `designation` VARCHAR(255) NOT NULL,
  `contact_number` VARCHAR(50) NOT NULL,
  `email` VARCHAR(255) NULL,
  `office_location` VARCHAR(255) NULL,
  `is_active` TINYINT(1) NOT NULL DEFAULT 1,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  FOREIGN KEY (`department_id`) REFERENCES `citizen_departments`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 3. Citizen Submissions Master Table
CREATE TABLE IF NOT EXISTS `citizen_submissions` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `reference_number` VARCHAR(100) NOT NULL UNIQUE,
  `candidate_id` VARCHAR(100) NOT NULL DEFAULT 'sachin-malik',
  `user_id` BIGINT UNSIGNED NULL,
  `citizen_name` VARCHAR(255) NOT NULL,
  `citizen_mobile` VARCHAR(20) NOT NULL,
  `citizen_email` VARCHAR(255) NULL,
  `department_id` INT UNSIGNED NOT NULL,
  `service_id` INT UNSIGNED NULL,
  `submission_type` ENUM('complaint', 'application', 'query', 'representation') NOT NULL DEFAULT 'complaint',
  `subject` VARCHAR(255) NOT NULL,
  `description` TEXT NOT NULL,
  `village` VARCHAR(150) NOT NULL DEFAULT 'कोपरगाव',
  `taluka` VARCHAR(100) NOT NULL DEFAULT 'कोपरगाव',
  `district` VARCHAR(100) NOT NULL DEFAULT 'अहिल्यानगर (अहमदनगर)',
  `address` TEXT NULL,
  `location_details` VARCHAR(255) NULL,
  `reference_application_number` VARCHAR(100) NULL,
  `status` ENUM('received', 'under_review', 'assigned', 'in_progress', 'resolved', 'closed', 'rejected') NOT NULL DEFAULT 'received',
  `priority` ENUM('normal', 'high', 'urgent') NOT NULL DEFAULT 'normal',
  `is_sensitive` TINYINT(1) NOT NULL DEFAULT 0,
  `assigned_officer_id` INT UNSIGNED NULL,
  `assigned_admin_id` BIGINT UNSIGNED NULL,
  `first_update_due_at` DATETIME NOT NULL,
  `first_update_sent_at` DATETIME NULL,
  `last_update_sent_at` DATETIME NULL,
  `sla_status` ENUM('pending', 'met', 'breached') NOT NULL DEFAULT 'pending',
  `internal_remarks` TEXT NULL,
  `citizen_visible_remarks` TEXT NULL,
  `resolution_summary` TEXT NULL,
  `device_token` VARCHAR(500) NULL,
  `source` VARCHAR(50) NOT NULL DEFAULT 'mobile_app',
  `resolved_at` DATETIME NULL,
  `closed_at` DATETIME NULL,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_cs_ref` (`reference_number`),
  INDEX `idx_cs_mobile` (`citizen_mobile`),
  INDEX `idx_cs_status` (`status`),
  INDEX `idx_cs_dept` (`department_id`),
  INDEX `idx_cs_sla` (`sla_status`, `first_update_due_at`),
  FOREIGN KEY (`department_id`) REFERENCES `citizen_departments`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 4. Grievance Timeline Actions Table (Citizen-Visible Progress Log)
CREATE TABLE IF NOT EXISTS `citizen_submission_actions` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `submission_id` BIGINT UNSIGNED NOT NULL,
  `previous_status` VARCHAR(50) NULL,
  `new_status` VARCHAR(50) NOT NULL,
  `action_type` VARCHAR(100) NOT NULL DEFAULT 'status_update',
  `title` VARCHAR(255) NOT NULL,
  `description` TEXT NOT NULL,
  `performed_by_name` VARCHAR(255) NOT NULL DEFAULT 'कार्यालय प्रशासक',

-- 5. Citizen Follow-Ups Table (Two-Way Messaging)
CREATE TABLE IF NOT EXISTS `citizen_submission_followups` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `submission_id` BIGINT UNSIGNED NOT NULL,
  `sender_type` ENUM('citizen', 'admin') NOT NULL DEFAULT 'citizen',
  `message` TEXT NOT NULL,
  `is_read_by_admin` TINYINT(1) NOT NULL DEFAULT 0,
  `is_read_by_citizen` TINYINT(1) NOT NULL DEFAULT 0,

  PRIMARY KEY (`id`),
  FOREIGN KEY (`submission_id`) REFERENCES `citizen_submissions`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

enum SubmissionStatus {
  received
  under_review
  assigned
  in_progress
  resolved
  closed
  rejected
}

enum SlaStatus {
  pending
  met
  breached
}

enum PriorityLevel {
  normal
  high
  urgent
}

model CitizenDepartment {
  id                    Int                @id @default(autoincrement())
  name                  String             @db.VarChar(255)
  code                  String             @unique @db.VarChar(100)
  description           String?            @db.Text
  icon                  String?            @default("Building2") @db.VarChar(100)
  departmentType        String             @default("general_governance") @map("department_type") @db.VarChar(100)
  responsibleOfficeName String?            @map("responsible_office_name") @db.VarChar(255)
  officeAddress         String?            @map("office_address") @db.VarChar(255)
  contactNumber         String?            @map("contact_number") @db.VarChar(50)
  officialPortalUrl     String?            @map("official_portal_url") @db.VarChar(255)
  displayOrder          Int                @default(1) @map("display_order")
  isActive              Boolean            @default(true) @map("is_active")
  officers              CitizenOfficer[]
  submissions           CitizenSubmission[]

  @@map("citizen_departments")
}

model CitizenOfficer {
  id             Int               @id @default(autoincrement())
  departmentId   Int               @map("department_id")
  name           String            @db.VarChar(255)
  designation    String            @db.VarChar(255)
  contactNumber  String            @map("contact_number") @db.VarChar(50)
  email          String?           @db.VarChar(255)
  isActive       Boolean           @default(true) @map("is_active")
  department     CitizenDepartment @relation(fields: [departmentId], references: [id], onDelete: Cascade)
  submissions    CitizenSubmission[]

  @@map("citizen_officers")
}

model CitizenSubmission {
  id                    BigInt                       @id @default(autoincrement())
  referenceNumber       String                       @unique @map("reference_number") @db.VarChar(100)
  candidateId           String                       @default("sachin-malik") @map("candidate_id") @db.VarChar(100)
  userId                BigInt?                      @map("user_id")
  citizenName           String                       @map("citizen_name") @db.VarChar(255)
  citizenMobile         String                       @map("citizen_mobile") @db.VarChar(20)
  citizenEmail          String?                      @map("citizen_email") @db.VarChar(255)
  departmentId          Int                          @map("department_id")
  serviceId             Int?                         @map("service_id")
  submissionType        String                       @default("complaint") @map("submission_type") @db.VarChar(50)
  subject               String                       @db.VarChar(255)
  description           String                       @db.Text
  village               String                       @default("कोपरगाव") @db.VarChar(150)
  taluka                String                       @default("कोपरगाव") @db.VarChar(100)
  district              String                       @default("अहिल्यानगर (अहमदनगर)") @db.VarChar(100)
  status                SubmissionStatus             @default(received)
  priority              PriorityLevel                @default(normal)
  isSensitive           Boolean                      @default(false) @map("is_sensitive")
  assignedOfficerId     Int?                         @map("assigned_officer_id")
  firstUpdateDueAt      DateTime                     @map("first_update_due_at")
  firstUpdateSentAt     DateTime?                    @map("first_update_sent_at")
  slaStatus             SlaStatus                    @default(pending) @map("sla_status")
  internalRemarks       String?                      @map("internal_remarks") @db.Text
  citizenVisibleRemarks String?                      @map("citizen_visible_remarks") @db.Text
  resolutionSummary     String?                      @map("resolution_summary") @db.Text
  deviceToken           String?                      @map("device_token") @db.VarChar(500)
  source                String                       @default("mobile_app") @db.VarChar(50)
  resolvedAt            DateTime?                    @map("resolved_at")
  createdAt             DateTime                     @default(now()) @map("created_at")
  updatedAt             DateTime                     @updatedAt @map("updated_at")

  department            CitizenDepartment            @relation(fields: [departmentId], references: [id])

  @@index([referenceNumber])
  @@index([citizenMobile])
  @@index([status])
  @@index([departmentId])
  @@map("citizen_submissions")

model CitizenSubmissionAction {
  id               BigInt            @id @default(autoincrement())
  submissionId     BigInt            @map("submission_id")
  previousStatus   String?           @map("previous_status") @db.VarChar(50)
  newStatus        String            @map("new_status") @db.VarChar(50)
  actionType       String            @default("status_update") @map("action_type") @db.VarChar(100)
  title            String            @db.VarChar(255)
  description      String            @db.Text

  createdAt    DateTime          @default(now()) @map("created_at")
  submission   CitizenSubmission @relation(fields: [submissionId], references: [id], onDelete: Cascade)

  @@map("citizen_submission_followups")
}

import { Request, Response } from 'express';
import { db } from '../config/database'; // mysql2/promise connection pool

export class CitizenGrievanceAdminController {
  /**
   * Admin: List all citizen submissions with SLA status & filters
   * GET /api/v1/admin/citizen-services/submissions
   */
  static async getSubmissions(req: Request, res: Response) {
    try {
      const page = Math.max(1, parseInt(req.query.page as string) || 1);
      const limit = Math.min(100, Math.max(1, parseInt(req.query.limit as string) || 20));
      const offset = (page - 1) * limit;
      const status = req.query.status as string;
      const deptId = req.query.department_id as string;
      const slaStatus = req.query.sla_status as string;
      const priority = req.query.priority as string;
      const search = (req.query.search as string || '').trim();

      let whereClauses: string[] = ['s.candidate_id = ?'];
      let queryParams: any[] = ['sachin-malik'];

      if (status && status !== 'all') {
        whereClauses.push('s.status = ?');
        queryParams.push(status);
      }

      if (deptId && deptId !== 'all') {
        whereClauses.push('s.department_id = ?');
        queryParams.push(deptId);
      }

      if (slaStatus && slaStatus !== 'all') {
        whereClauses.push('s.sla_status = ?');
        queryParams.push(slaStatus);
      }

      if (priority && priority !== 'all') {
        whereClauses.push('s.priority = ?');
        queryParams.push(priority);
      }

      if (search) {
        whereClauses.push('(s.reference_number LIKE ? OR s.citizen_name LIKE ? OR s.citizen_mobile LIKE ? OR s.subject LIKE ? OR s.village LIKE ?)');
        const searchLike = `%${search}%`;
        queryParams.push(searchLike, searchLike, searchLike, searchLike, searchLike);
      }

      const whereSql = `WHERE ${whereClauses.join(' AND ')}`;

      // 1. Count Total
      const [countResult]: any = await db.query(
        `SELECT COUNT(*) as total FROM citizen_submissions s ${whereSql}`,
        queryParams
      );
      const total = countResult[0]?.total || 0;

      // 2. Query Rows with Department and Officer Joined
      const [rows]: any = await db.query(
        `SELECT s.id, s.reference_number, s.citizen_name, s.citizen_mobile, s.citizen_email,
                s.department_id, s.service_id, s.submission_type, s.subject, s.description,
                s.village, s.taluka, s.district, s.status, s.priority, s.is_sensitive,
                s.first_update_due_at, s.first_update_sent_at, s.sla_status,
                s.internal_remarks, s.citizen_visible_remarks, s.resolution_summary,
                s.created_at, s.updated_at,
                d.name as department_name, d.code as department_code, d.icon as department_icon,
                o.id as officer_id, o.name as officer_name, o.designation as officer_designation, o.contact_number as officer_contact
         FROM citizen_submissions s
         LEFT JOIN citizen_departments d ON s.department_id = d.id
         LEFT JOIN citizen_officers o ON s.assigned_officer_id = o.id
         ${whereSql}
         ORDER BY s.created_at DESC
         LIMIT ? OFFSET ?`,
        [...queryParams, limit, offset]
      );

      // 3. Format items
      const items = rows.map((r: any) => ({
        id: r.id,
        reference_number: r.reference_number,
        citizen_name: r.citizen_name,
        citizen_mobile: r.citizen_mobile,
        citizen_email: r.citizen_email,
        department_id: r.department_id,
        department: {
          id: r.department_id,
          name: r.department_name,
          code: r.department_code,
          icon: r.department_icon,
        },
        submission_type: r.submission_type,
        subject: r.subject,
        description: r.description,
        village: r.village,
        taluka: r.taluka,
        district: r.district,
        status: r.status,
        priority: r.priority,
        is_sensitive: Boolean(r.is_sensitive),
        first_update_due_at: r.first_update_due_at,
        first_update_sent_at: r.first_update_sent_at,
        sla_status: r.sla_status,
        internal_remarks: r.internal_remarks,
        citizen_visible_remarks: r.citizen_visible_remarks,
        assignedOfficer: r.officer_id ? {
          id: r.officer_id,
          name: r.officer_name,
          designation: r.officer_designation,
          contact_number: r.officer_contact,
        } : null,
        created_at: r.created_at,
        updated_at: r.updated_at,
      }));

      // 4. Calculate KPI Dashboard Metrics
      const [kpiRows]: any = await db.query(
        `SELECT 
           COUNT(*) as total,
           SUM(status = 'received') as received,
           SUM(status = 'under_review') as underReview,
           SUM(status = 'assigned') as assigned,
           SUM(status = 'in_progress') as inProgress,
           SUM(status = 'resolved') as resolved,
           SUM(status = 'rejected') as rejected,
           SUM(sla_status = 'breached') as slaBreachedCount,
           SUM(sla_status = 'met') as slaMetCount
         FROM citizen_submissions
         WHERE candidate_id = 'sachin-malik'`
      );
      const kpi = kpiRows[0] || {};
      const totalSla = (kpi.slaMetCount || 0) + (kpi.slaBreachedCount || 0);
      const slaRate = totalSla > 0 ? `${((kpi.slaMetCount / totalSla) * 100).toFixed(1)}%` : '100%';

      return res.json({
        success: true,
        data: {
          items,
          pagination: {
            total,
            page,
            limit,
            totalPages: Math.ceil(total / limit),
          },
          kpiMetrics: {
            total: kpi.total || 0,
            received: kpi.received || 0,
            underReview: kpi.underReview || 0,
            assigned: kpi.assigned || 0,
            inProgress: kpi.inProgress || 0,
            resolved: kpi.resolved || 0,
            rejected: kpi.rejected || 0,
            slaBreachedCount: kpi.slaBreachedCount || 0,
            slaAdherenceRate: slaRate,
          },
        },
      });
    } catch (error: any) {
      console.error('[CitizenGrievanceAdminController] getSubmissions error:', error);
      return res.status(500).json({ success: false, message: 'Server error' });
    }
  }

  /**
   * Admin: Assign Officer & Department to Submission
   * POST /api/v1/admin/citizen-services/submissions/:id/assign
   */
  static async assignOfficer(req: Request, res: Response) {
    const connection = await db.getConnection();
    try {
      await connection.beginTransaction();
      const { id } = req.params;
      const { department_id, assigned_officer_id, priority = 'normal', remarks } = req.body;

      if (!department_id || !assigned_officer_id) {
        return res.status(400).json({ success: false, message: 'विभाग आणि अधिकारी दोन्ही निवडणे आवश्यक आहे.' });
      }

      // 1. Get Officer details
      const [officerRows]: any = await connection.query(
        `SELECT name, designation FROM citizen_officers WHERE id = ?`,
        [assigned_officer_id]
      );
      const officer = officerRows[0];
      const officerTitle = officer ? `${officer.name} (${officer.designation})` : 'नोडल अधिकारी';

      // 2. Update Submission
      await connection.query(
        `UPDATE citizen_submissions 
         SET department_id = ?, assigned_officer_id = ?, priority = ?, status = 'assigned',
             internal_remarks = COALESCE(?, internal_remarks), updated_at = NOW()
         WHERE id = ?`,
        [department_id, assigned_officer_id, priority, remarks || null, id]
      );

      // 3. Log Timeline Action
      await connection.query(
        `INSERT INTO citizen_submission_actions 
         (submission_id, previous_status, new_status, action_type, title, description, performed_by_name)
         VALUES (?, 'received', 'assigned', 'officer_assigned', 'अधिकारी नेमणूक पूर्ण', ?, 'कार्यालय प्रशासक')`,
        [id, `तक्रार संबंधित अधिकारी ${officerTitle} यांच्याकडे पुढील कार्यवाहीसाठी वर्ग केली आहे.`]
      );

      await connection.commit();
      return res.json({ success: true, message: 'तक्रार संबंधित अधिकाऱ्याकडे यशस्वीरीत्या वर्ग झाली.' });
    } catch (error: any) {
      await connection.rollback();
      console.error('[assignOfficer error]:', error);
      return res.status(500).json({ success: false, message: 'Server error' });
    } finally {
      connection.release();
    }
  }

use App\Http\Controllers\Controller;

    public function index(Request $request)
    {
        $query = CitizenSubmission::with(['department', 'assignedOfficer']);

            $query->where('status', $request->status);
        }
        if ($request->filled('department_id') && $request->department_id !== 'all') {

        }
        if ($request->filled('sla_status') && $request->sla_status !== 'all') {
            $query->where('sla_status', $request->sla_status);
        }
        if ($request->filled('search')) {

            $query->where(function ($q) use ($s) {
                $q->where('reference_number', 'like', $s)
                  ->orWhere('citizen_name', 'like', $s)
                  ->orWhere('citizen_mobile', 'like', $s)
                  ->orWhere('subject', 'like', $s)
                  ->orWhere('village', 'like', $s);
            });
        }

        $submissions = $query->orderBy('created_at', 'desc')->paginate($request->input('limit', 20));

        return response()->json([

                    'resolved' => CitizenSubmission::where('status', 'resolved')->count(),

                ]
            ]
        ]);

    // POST /api/v1/admin/citizen-services/submissions/{id}/assign
    public function assign(Request $request, $id)
    {
        $validated = $request->validate([
            'department_id'       => 'required|integer',
            'assigned_officer_id' => 'required|integer',
            'priority'            => 'nullable|string',
        ]);

        DB::transaction(function () use ($id, $validated, $request) {
            $submission = CitizenSubmission::findOrFail($id);
            $submission->update([
                'department_id'       => $validated['department_id'],
                'assigned_officer_id' => $validated['assigned_officer_id'],
                'priority'            => $validated['priority'] ?? 'normal',
                'status'              => 'assigned',
            ]);

            $officer = CitizenOfficer::find($validated['assigned_officer_id']);
            $officerName = $officer ? "{$officer->name} ({$officer->designation})" : "नोडल अधिकारी";

            CitizenSubmissionAction::create([
                'submission_id'     => $id,
                'previous_status'   => 'received',
                'new_status'        => 'assigned',
                'action_type'       => 'officer_assigned',
                'title'             => 'अधिकारी नेमणूक पूर्ण',

            ]);
        });

        return response()->json(['success' => true, 'message' => 'अधिकारी यशस्वीरीत्या नेमला गेला.']);
    }

    // POST /api/v1/admin/citizen-services/submissions/{id}/sla-update
    public function slaUpdate(Request $request, $id)
    {
        $validated = $request->validate(['remarks' => 'required|string']);

        DB::transaction(function () use ($id, $validated) {
            $submission = CitizenSubmission::findOrFail($id);
            $submission->update([
                'citizen_visible_remarks' => $validated['remarks'],
                'first_update_sent_at'    => Carbon::now(),
                'last_update_sent_at'     => Carbon::now(),
                'sla_status'              => 'met',
            ]);

            CitizenSubmissionAction::create([
                'submission_id'     => $id,
                'new_status'        => $submission->status,
                'action_type'       => 'sla_update',
                'title'             => '२४-तास प्रथम प्रगती अद्यतन',
                'description'       => $validated['remarks'],
                'performed_by_name' => 'मा. श्री. सचिन मलिक कार्यालय',
            ]);
        });

        return response()->json(['success' => true, 'message' => '२४-तास SLA अद्यतन यशस्वीरीत्या नोंदवले.']);
    }
}
