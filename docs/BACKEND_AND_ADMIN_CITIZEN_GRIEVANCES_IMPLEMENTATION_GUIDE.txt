1. EXECUTIVE SUMMARY & ROOT CAUSE ANALYSIS
================================================================================

PROBLEM STATEMENT:
When citizens submitted complaints through the "नागरिक सेवा आणि तक्रार निवारण"
(Civic Services & Grievance Redressal) section in the mobile app, the complaints
did NOT appear in the Web Admin Panel.

TECHNICAL ROOT CAUSE:
The backend and admin panel maintain two separate data channels:

1. Channel A (General Issues):
   - Endpoints: GET /api/v1/issues, POST /api/v1/issues
   - Table: `issues`
   - Used by: The original "समस्या नोंदवा (Report Issue)" screen.
   - Admin Panel Location: The primary "तक्रारी (Complaints)" menu.

2. Channel B (Civic Services 26-Department Grievance System):
   - Endpoints: POST /api/v1/citizen-services/submissions
   - Admin Endpoint: GET /api/v1/admin/citizen-services/submissions
   - Table: `citizen_submissions`
   - Used by: The new 26-department "नागरिक सेवा व तक्रार" section.

DISCREPANCIES IDENTIFIED:
a) The Web Admin Panel's primary complaints table was ONLY fetching from Channel A
   (`GET /api/v1/issues`). When a user submitted from Channel B, it was stored
   in `citizen_submissions` but never appeared in Channel A!
b) The admin route for Channel B is `GET /api/v1/admin/citizen-services/submissions`.
   Calling `GET /api/v1/citizen-services/submissions` (missing `/admin/`) returned
   HTTP 404 Route Not Found.
c) If the admin panel developer did not integrate the Channel B admin route,
   those complaints remained invisible in the admin dashboard.

================================================================================
2. DUAL-CHANNEL RESOLUTION IMPLEMENTED IN MOBILE APP
================================================================================

We have updated the mobile app (`src/app/new-citizen-submission.tsx`) with an
automated Dual-Sync architecture:

1. Primary Submission (Channel B):
   Submits to `POST /api/v1/citizen-services/submissions` with department_id,
   service_id, citizen details, and 24-hour SLA calculation.
   Generates official reference code (e.g., `CSK-2026-000005`).

2. Instant Dual-Sync (Channel A):
   Simultaneously mirrors the complaint to `POST /api/v1/issues` with:
   - title: `[Department Name] Subject`
   - description: Includes full details, Department, Village, and Reference Code
   - category: Automatically mapped to appropriate issue category (roads, water,
     electricity, cleanliness, drain, health, education, etc.)
   - userMobile & userName: Citizen's verified mobile number and name.

BENEFITS:
- If the Admin Panel checks the main "तक्रारी (Issues)" table -> The complaint
  shows up INSTANTLY at the top of the table.
- If the Admin Panel checks the "नागरिक सेवा (Citizen Services)" table -> The
  complaint shows up there with complete department and SLA metrics.
- Zero data loss under any circumstance.

CREATE TABLE IF NOT EXISTS `citizen_departments` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(255) NOT NULL,
  `code` VARCHAR(100) NOT NULL UNIQUE,
  `description` TEXT NULL,
  `icon` VARCHAR(50) DEFAULT 'Building2',
  `display_order` INT DEFAULT 0,
  `department_type` VARCHAR(100) DEFAULT 'general_governance',
  `responsible_office_name` VARCHAR(255) NULL,
  `office_address` VARCHAR(255) NULL,
  `contact_number` VARCHAR(50) NULL,
  `official_portal_url` VARCHAR(255) NULL,
  `instructions` TEXT NULL,
  `emergency_contact` VARCHAR(50) NULL,
  `is_sensitive` BOOLEAN DEFAULT FALSE,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 2. Citizen Submissions Table (Grievances & Service Requests)
CREATE TABLE IF NOT EXISTS `citizen_submissions` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `reference_number` VARCHAR(50) NOT NULL UNIQUE,
  `user_id` INT NULL,
  `citizen_name` VARCHAR(255) NOT NULL,
  `citizen_mobile` VARCHAR(20) NOT NULL,
  `citizen_email` VARCHAR(255) NULL,
  `department_id` INT NOT NULL,
  `service_id` INT NULL,
  `submission_type` ENUM('complaint', 'application', 'request') DEFAULT 'complaint',
  `subject` VARCHAR(500) NOT NULL,
  `description` LONGTEXT NOT NULL,
  `village` VARCHAR(150) DEFAULT 'कोपरगाव',
  `taluka` VARCHAR(100) DEFAULT 'कोपरगाव',
  `district` VARCHAR(100) DEFAULT 'अहिल्यानगर (अहमदनगर)',
  `address` TEXT NULL,
  `location_details` TEXT NULL,
  `status` ENUM('received', 'assigned', 'in_progress', 'resolved', 'rejected', 'escalated') DEFAULT 'received',
  `priority` ENUM('low', 'normal', 'high', 'urgent') DEFAULT 'normal',
  `is_sensitive` BOOLEAN DEFAULT FALSE,
  `assigned_officer_id` INT NULL,
  `assigned_admin_id` INT NULL,
  `first_update_due_at` DATETIME NULL,
  `first_update_sent_at` DATETIME NULL,
  `last_update_sent_at` DATETIME NULL,
  `sla_status` ENUM('pending', 'met', 'breached') DEFAULT 'pending',
  `internal_remarks` TEXT NULL,
  `citizen_visible_remarks` TEXT NULL,
  `device_token` VARCHAR(500) NULL,
  `source` VARCHAR(50) DEFAULT 'mobile_app',
  `resolved_at` DATETIME NULL,
  `closed_at` DATETIME NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_dept (`department_id`),
  INDEX idx_mobile (`citizen_mobile`),
  INDEX idx_status (`status`),
  INDEX idx_ref (`reference_number`),
  FOREIGN KEY (`department_id`) REFERENCES `citizen_departments`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 3. Officers / Department Contacts
CREATE TABLE IF NOT EXISTS `department_officers` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `department_id` INT NOT NULL,
  `name` VARCHAR(255) NOT NULL,
  `designation` VARCHAR(150) NOT NULL,
  `contact_number` VARCHAR(50) NOT NULL,
  `email` VARCHAR(150) NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

```javascript
const db = require('../config/db'); // Your database connection pool

// 1. Get all citizen submissions for admin
exports.getAdminSubmissions = async (req, res) => {
  try {
    const page = parseInt(req.query.page) || 1;
    const limit = parseInt(req.query.limit) || 20;
    const offset = (page - 1) * limit;

    const { status, department_id, search, submission_type } = req.query;

    let whereConditions = [];
    let queryParams = [];

    if (status && status !== 'all') {
      whereConditions.push('s.status = ?');
      queryParams.push(status);
    }

    if (department_id) {
      whereConditions.push('s.department_id = ?');
      queryParams.push(parseInt(department_id));
    }

    if (submission_type) {
      whereConditions.push('s.submission_type = ?');
      queryParams.push(submission_type);
    }

    if (search && search.trim()) {
      const s = `%${search.trim()}%`;
      whereConditions.push('(s.reference_number LIKE ? OR s.citizen_name LIKE ? OR s.citizen_mobile LIKE ? OR s.subject LIKE ? OR s.village LIKE ?)');
      queryParams.push(s, s, s, s, s);
    }

    const whereClause = whereConditions.length > 0 ? `WHERE ${whereConditions.join(' AND ')}` : '';

    // Count Total
    const countQuery = `SELECT COUNT(*) as total FROM citizen_submissions s ${whereClause}`;
    const [countResult] = await db.query(countQuery, queryParams);
    const total = countResult[0]?.total || 0;

    // Fetch Records
    const selectQuery = `
      SELECT 
        s.*,
        d.name as department_name,
        d.code as department_code,
        d.icon as department_icon,
        o.name as officer_name,
        o.designation as officer_designation,
        o.contact_number as officer_contact
      FROM citizen_submissions s
      LEFT JOIN citizen_departments d ON s.department_id = d.id
      LEFT JOIN department_officers o ON s.assigned_officer_id = o.id
      ${whereClause}
      ORDER BY s.id DESC
      LIMIT ? OFFSET ?
    `;

    const fetchParams = [...queryParams, limit, offset];
    const [rows] = await db.query(selectQuery, fetchParams);

    const items = rows.map(r => ({
      id: r.id,
      reference_number: r.reference_number,
      citizen_name: r.citizen_name,
      citizen_mobile: r.citizen_mobile,
      citizen_email: r.citizen_email,
      department_id: r.department_id,
      department: {
        id: r.department_id,
        name: r.department_name,
        code: r.department_code,
        icon: r.department_icon
      },
      submission_type: r.submission_type,
      subject: r.subject,
      description: r.description,
      village: r.village,
      status: r.status,
      priority: r.priority,
      assignedOfficer: r.officer_name ? {
        id: r.assigned_officer_id,
        name: r.officer_name,
        designation: r.officer_designation,
        contact_number: r.officer_contact
      } : null,
      first_update_due_at: r.first_update_due_at,
      sla_status: r.sla_status,
      internal_remarks: r.internal_remarks,
      citizen_visible_remarks: r.citizen_visible_remarks,
      created_at: r.created_at,
      updated_at: r.updated_at
    }));

    return res.status(200).json({
      success: true,
      message: 'Success',
      data: {
        total,
        page,
        limit,
        totalPages: Math.ceil(total / limit),
        items
      }
    });
  } catch (error) {
    console.error('Error fetching admin submissions:', error);
    return res.status(500).json({ success: false, message: 'सर्व्हर त्रुटी आली.' });
  }
};

// 2. Update grievance status
exports.updateSubmissionStatus = async (req, res) => {
  try {
    const id = req.params.id;
    const { status, citizen_visible_remarks, internal_remarks, assigned_officer_id } = req.body;

    const updates = [];
    const params = [];

    if (status) {
      updates.push('status = ?');
      params.push(status);
      if (status === 'resolved') {
        updates.push('resolved_at = NOW()');
      }
    }

    if (citizen_visible_remarks !== undefined) {
      updates.push('citizen_visible_remarks = ?');
      params.push(citizen_visible_remarks);
      updates.push('last_update_sent_at = NOW()');
      updates.push('first_update_sent_at = COALESCE(first_update_sent_at, NOW())');
      updates.push('sla_status = "met"');
    }

    if (internal_remarks !== undefined) {
      updates.push('internal_remarks = ?');
      params.push(internal_remarks);
    }

    if (assigned_officer_id !== undefined) {
      updates.push('assigned_officer_id = ?');
      params.push(assigned_officer_id);
    }

    if (updates.length === 0) {
      return res.status(400).json({ success: false, message: 'No updates provided.' });
    }

    params.push(id);
    const sql = `UPDATE citizen_submissions SET ${updates.join(', ')} WHERE id = ?`;
    await db.query(sql, params);

    return res.status(200).json({
      success: true,
      message: 'तक्रारीची स्थिती यशस्वीरीत्या अद्यतनित करण्यात आली.'
    });
  } catch (error) {
    console.error('Error updating submission status:', error);
    return res.status(500).json({ success: false, message: 'अपडेट करताना त्रुटी आली.' });
  }
};
```

```jsx
            value={deptFilter}
            onChange={(e) => setDeptFilter(e.target.value)}
            className="w-full px-3 py-2 border border-slate-200 rounded-lg text-sm bg-white focus:outline-none focus:ring-2 focus:ring-orange-500"
          >
            <option value="">सर्व विभाग (All 26 Departments)</option>
            {departments.map((d) => (
              <option key={d.id} value={d.id}>{d.name}</option>
            ))}
          </select>
        </div>

        {/* Status Filter */}
        <div className="w-48">
          <select
            value={statusFilter}
            onChange={(e) => setStatusFilter(e.target.value)}
            className="w-full px-3 py-2 border border-slate-200 rounded-lg text-sm bg-white focus:outline-none focus:ring-2 focus:ring-orange-500"
          >
            <option value="all">सर्व स्थिती (All Status)</option>
            <option value="received">नवीन (Received)</option>
            <option value="assigned">वर्ग केली (Assigned)</option>
            <option value="in_progress">प्रगतीपथावर (In Progress)</option>
            <option value="resolved">निकाली (Resolved)</option>
            <option value="rejected">नाकारली (Rejected)</option>
          </select>
        </div>

        <button
          onClick={fetchSubmissions}
          className="px-4 py-2 bg-orange-600 hover:bg-orange-700 text-white font-bold text-sm rounded-lg transition"
        >
          रिफ्रेश करा
        </button>
      </div>

      {/* Table */}
      <div className="bg-white rounded-xl shadow-sm border border-slate-200 overflow-hidden">
        {loading ? (
          <div className="p-12 text-center text-slate-400">माहिती लोड होत आहे...</div>
        ) : submissions.length === 0 ? (
          <div className="p-12 text-center text-slate-400 font-semibold">कोणत्याही तक्रारी आढळल्या नाहीत.</div>
        ) : (
          <div className="overflow-x-auto">
            <table className="w-full text-left text-sm">
              <thead className="bg-slate-100 text-slate-700 text-xs font-bold uppercase tracking-wider">
                <tr>
                  <th className="p-4">संदर्भ क्र.</th>
                  <th className="p-4">नागरिकाचे नाव व संपर्क</th>
                  <th className="p-4">शासकीय विभाग</th>
                  <th className="p-4">विषय</th>
                  <th className="p-4">गाव/शहर</th>
                  <th className="p-4">स्थिती</th>
                  <th className="p-4">नोंदणी तारीख</th>
                  <th className="p-4 text-center">कृती</th>
                </tr>
              </thead>
              <tbody className="divide-y divide-slate-100">
                {submissions.map((item) => (
                  <tr key={item.id} className="hover:bg-slate-50 transition">
                    <td className="p-4 font-mono font-bold text-orange-600">
                      {item.reference_number}
                    </td>
                    <td className="p-4">
                      <div className="font-bold text-slate-800">{item.citizen_name}</div>
                      <a href={`tel:${item.citizen_mobile}`} className="text-xs text-blue-600 hover:underline">
                        📞 {item.citizen_mobile}
                      </a>
                    </td>
                    <td className="p-4 font-semibold text-slate-700">
                      {item.department?.name || 'शासकीय विभाग'}
                    </td>
                    <td className="p-4 max-w-xs truncate text-slate-600 font-medium">
                      {item.subject}
                    </td>
                    <td className="p-4 text-slate-600 font-medium">
                      {item.village || 'कोपरगाव'}
                    </td>
                    <td className="p-4">
                      {getStatusBadge(item.status)}
                    </td>
                    <td className="p-4 text-xs text-slate-500">
                      {new Date(item.created_at).toLocaleDateString('mr-IN', {
                        day: '2-digit', month: 'short', year: 'numeric'
                      })}
                    </td>
                    <td className="p-4 text-center">
                      <button
                        onClick={() => {
                          setSelectedItem(item);
                          setNewStatus(item.status);
                          setCitizenRemarks(item.citizen_visible_remarks || '');
                          setInternalRemarks(item.internal_remarks || '');
                        }}
                        className="px-3 py-1.5 bg-slate-800 hover:bg-slate-900 text-white rounded-lg text-xs font-bold transition"
                      >
                        पहा / अपडेट करा
                      </button>
                    </td>
                  </tr>
                ))}
              </tbody>
            </table>
          </div>
        )}
      </div>

      {/* Detail & Status Modal */}
      {selectedItem && (
        <div className="fixed inset-0 bg-black/50 backdrop-blur-sm flex items-center justify-center p-4 z-50">
          <div className="bg-white rounded-2xl max-w-2xl w-full max-h-[90vh] overflow-y-auto p-6 shadow-2xl">
            <div className="flex justify-between items-center border-b pb-3 mb-4">
              <div>
                <h2 className="text-lg font-black text-slate-800">तक्रार तपशील</h2>
                <span className="text-xs font-mono font-bold text-orange-600">{selectedItem.reference_number}</span>
              </div>
              <button onClick={() => setSelectedItem(null)} className="text-slate-400 hover:text-slate-600 text-xl font-bold">✕</button>
            </div>

            <div className="space-y-4 text-sm text-slate-700">
              <div className="grid grid-cols-2 gap-4 bg-slate-50 p-4 rounded-xl">
                <div>
                  <span className="text-xs text-slate-400 block font-bold">नागरिकाचे नाव</span>
                  <span className="font-bold">{selectedItem.citizen_name}</span>
                </div>
                <div>
                  <span className="text-xs text-slate-400 block font-bold">मोबाईल क्रमांक</span>
                  <a href={`tel:${selectedItem.citizen_mobile}`} className="font-bold text-blue-600">📞 {selectedItem.citizen_mobile}</a>
                </div>
                <div>
                  <span className="text-xs text-slate-400 block font-bold">संबंधित विभाग</span>
                  <span className="font-bold text-orange-600">{selectedItem.department?.name}</span>
                </div>
                <div>
                  <span className="text-xs text-slate-400 block font-bold">गाव / वार्ड</span>
                  <span className="font-bold">{selectedItem.village || 'कोपरगाव'}</span>
                </div>
              </div>

              <div>
                <span className="text-xs text-slate-400 block font-bold mb-1">तक्रारीचा विषय</span>
                <p className="font-bold text-slate-900 bg-slate-50 p-3 rounded-lg">{selectedItem.subject}</p>
              </div>

              <div>
                <span className="text-xs text-slate-400 block font-bold mb-1">सविस्तर वर्णन</span>
                <p className="bg-slate-50 p-3 rounded-lg text-slate-800 whitespace-pre-line leading-relaxed">{selectedItem.description}</p>
              </div>

              {/* Status Update Form */}
              <div className="border-t pt-4 space-y-3">
                <h3 className="font-black text-slate-800">कार्यालयीन कृती व स्थिती अद्यतन:</h3>

                <div>
                  <label className="text-xs font-bold text-slate-600 block mb-1">नवीन स्थिती निवडा:</label>
                  <select
                    value={newStatus}
                    onChange={(e) => setNewStatus(e.target.value)}
                    className="w-full px-3 py-2 border rounded-lg bg-white font-bold"
                  >
                    <option value="received">नवीन प्राप्त (Received)</option>
                    <option value="assigned">अधिकारी वर्ग केली (Assigned)</option>
                    <option value="in_progress">काम प्रगतीपथावर (In Progress)</option>
                    <option value="resolved">तक्रार निवारण पूर्ण (Resolved)</option>
                    <option value="rejected">नाकारली (Rejected)</option>
                  </select>
                </div>

                <div>
                  <label className="text-xs font-bold text-slate-600 block mb-1">
                    नागरिकाला दिसणारा शेरा (Citizen-Visible Update Remark):
                  </label>
                  <textarea
                    rows={3}
                    placeholder="उदा. आपल्या अर्जाची प्रत्यक्ष पाहणी करण्यात आली असून संबंधित विभागाला तातडीने काम पूर्ण करण्याचे आदेश दिले आहेत."
                    value={citizenRemarks}
                    onChange={(e) => setCitizenRemarks(e.target.value)}
                    className="w-full p-3 border rounded-lg text-sm"
                  />
                </div>

                <div>
                  <label className="text-xs font-bold text-slate-600 block mb-1">अंतर्गत कार्यालयीन टिप्पणी (Internal Note):</label>
                  <input
                    type="text"
                    placeholder="कार्यालयीन नोंदीसाठी टिप्पणी..."
                    value={internalRemarks}
                    onChange={(e) => setInternalRemarks(e.target.value)}
                    className="w-full p-2.5 border rounded-lg text-sm"
                  />
                </div>
              </div>
            </div>

            <div className="flex justify-end gap-3 border-t pt-4 mt-4">
              <button
                onClick={() => setSelectedItem(null)}
                className="px-4 py-2 border rounded-lg font-bold text-slate-600 hover:bg-slate-50"
              >
                रद्द करा
              </button>
              <button
                onClick={handleUpdateStatus}
                disabled={saving}
                className="px-6 py-2 bg-orange-600 hover:bg-orange-700 text-white font-black rounded-lg shadow-md transition disabled:opacity-50"
              >
                {saving ? 'सेव्ह होत आहे...' : 'शेरा व स्थिती सेव्ह करा'}
              </button>
            </div>
          </div>
        </div>
      )}
    </div>
  );
}
```
